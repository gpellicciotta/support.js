# Support Words.js
Dutch and English word lists for word-based games and utilities.

Part of the [support.js](../../README.md) repository, versioned in lockstep with `@gpellicciotta/support.js`.

## Installing
```bash
npm install @gpellicciotta/support-words.js
```

## Usage
```javascript
import { SIMPLE_DUTCH_WORDS } from '@gpellicciotta/support-words.js/dutchwords.mjs';
import { SIMPLE_ENGLISH_WORDS } from '@gpellicciotta/support-words.js/englishwords.mjs';
```

## Migrating from support.js 2.x
Replace imports of `@gpellicciotta/support.js/dutchwords.mjs` and `@gpellicciotta/support.js/englishwords.mjs`
with the paths above, and add the dependency on `@gpellicciotta/support-words.js`.
